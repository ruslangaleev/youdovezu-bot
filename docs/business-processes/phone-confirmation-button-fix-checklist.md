# Чек-лист: Исправление проблемы с кнопкой "Подтвердить номер телефона" в Telegram боте

## Проблема
После подтверждения номера телефона в Telegram боте, кнопка "📱 Подтвердить номер телефона" (ReplyKeyboard) не исчезает, хотя регистрация уже завершена.

## Анализ проблемы

### Текущая логика:
1. **Отправка запроса на подтверждение номера**:
   - `TelegramBotService.SendPhoneConfirmationRequestAsync()` отправляет сообщение с `ReplyKeyboardMarkup`
   - Клавиатура содержит кнопку "📱 Подтвердить номер телефона"
   - Установлено `OneTimeKeyboard = true`, но это не всегда работает надежно

2. **Обработка подтверждения номера**:
   - `BotController.ProcessContactMessage()` обрабатывает контакт (номер телефона)
   - Вызывается `UserService.UpdatePhoneNumberAsync()` для обновления номера в БД
   - Отправляется сообщение о завершении регистрации
   - ❌ **Проблема**: Клавиатура с кнопкой не удаляется явно
   - ❌ **Проблема**: Не вызывается `SendMainMenuAsync()` для показа главного меню

### Корневая причина:
После подтверждения номера телефона клавиатура с кнопкой "📱 Подтвердить номер телефона" не удаляется явно, и не показывается главное меню. Пользователь видит старое сообщение с кнопкой, хотя регистрация уже завершена.

## Чек-лист решения

### 1. Backend: Удалить клавиатуру после подтверждения номера

- [ ] **Метод**: `ProcessContactMessage()` (строка ~241)

- [ ] **Действие**: 
  1. Удалить клавиатуру, отправив сообщение с `ReplyKeyboardRemove`
  2. Вызвать `SendMainMenuAsync()` для показа главного меню
- [ ] **Код**:

## Технические детали

### ReplyKeyboardRemove в Telegram Bot API:
- `ReplyKeyboardRemove` - специальный тип клавиатуры, который удаляет текущую ReplyKeyboard
- Должен быть отправлен в `replyMarkup` параметре `SendTextMessageAsync`
- После удаления клавиатуры пользователь не увидит кнопки внизу экрана

### OneTimeKeyboard:
- `OneTimeKeyboard = true` в `ReplyKeyboardMarkup` должен автоматически скрывать клавиатуру после нажатия
- Но это работает не всегда надежно, особенно если отправляется новое сообщение
- Явное удаление через `ReplyKeyboardRemove` более надежно

---

## Примечания

- Убедитесь, что `ReplyKeyboardRemove` импортирован из `Telegram.Bot.Types.ReplyMarkups`
- После удаления клавиатуры можно отправить новое сообщение с InlineKeyboard (главное меню)
- Главное меню должно показываться только после полной регистрации (согласие с ПД + подтверждение номера)
