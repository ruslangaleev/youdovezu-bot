# Простая инструкция: Настройка SSH ключа для GitHub Actions

## Что такое authorized_keys?

`authorized_keys` - это файл на вашем VPS сервере, который содержит список публичных SSH ключей, которым разрешено подключаться к серверу без пароля. Когда GitHub Actions пытается подключиться к серверу, сервер проверяет, есть ли публичный ключ в этом файле.

## Пошаговая инструкция

### Шаг 1: Ключ уже создан ✅

Вы уже выполнили:
```bash
ssh-keygen -t ed25519 -C "github-actions-deploy" -f ~/.ssh/github_actions_deploy
```

Теперь у вас есть два файла:
- `~/.ssh/github_actions_deploy` - **приватный ключ** (секретный, для GitHub)
- `~/.ssh/github_actions_deploy.pub` - **публичный ключ** (для сервера)

---

### Шаг 2: Скопировать публичный ключ на сервер

**Вариант А: Автоматически (проще всего)**

```bash
ssh-copy-id -i ~/.ssh/github_actions_deploy.pub ваш_пользователь@ваш_сервер_ip
```

**Пример:**
```bash
ssh-copy-id -i ~/.ssh/github_actions_deploy.pub deploy@192.168.1.100
```

**Что произойдет:**
- Команда попросит ввести пароль от сервера (в последний раз)
- Автоматически создаст папку `~/.ssh` на сервере (если её нет)
- Добавит ваш публичный ключ в файл `~/.ssh/authorized_keys`
- Установит правильные права доступа

**Если команда не работает (Windows):**

Используйте Вариант Б ниже.

---

**Вариант Б: Вручную (если ssh-copy-id не работает)**

#### 2.1. Посмотрите содержимое публичного ключа:

```bash
cat ~/.ssh/github_actions_deploy.pub
```

Вы увидите что-то вроде:
```
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIG... github-actions-deploy
```

**Скопируйте всю эту строку** (от `ssh-ed25519` до конца).

#### 2.2. Подключитесь к серверу:

```bash
ssh ваш_пользователь@ваш_сервер_ip
```

**Пример:**
```bash
ssh deploy@192.168.1.100
```

Введите пароль для входа на сервер.

#### 2.3. На сервере создайте папку и файл (если их нет):

```bash
mkdir -p ~/.ssh
chmod 700 ~/.ssh
```

#### 2.4. Добавьте публичный ключ в authorized_keys:

```bash
echo "ваш_публичный_ключ_из_шага_2.1" >> ~/.ssh/authorized_keys
```

**Пример:**
```bash
echo "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIG... github-actions-deploy" >> ~/.ssh/authorized_keys
```

#### 2.5. Установите правильные права:

```bash
chmod 600 ~/.ssh/authorized_keys
```

#### 2.6. Выйдите с сервера:

```bash
exit
```

---

### Шаг 3: Проверьте, что всё работает

Попробуйте подключиться к серверу **без пароля**:

```bash
ssh -i ~/.ssh/github_actions_deploy ваш_пользователь@ваш_сервер_ip
```

**Пример:**
```bash
ssh -i ~/.ssh/github_actions_deploy deploy@192.168.1.100
```

**Если подключение прошло без запроса пароля** - всё настроено правильно! ✅

**Если всё ещё просит пароль:**
- Проверьте, что вы скопировали ключ правильно
- Проверьте права на файлы на сервере:
  ```bash
  ssh ваш_пользователь@ваш_сервер_ip
  ls -la ~/.ssh/
  # Должно быть:
  # -rw------- authorized_keys (права 600)
  # drwx------ . (права 700)
  ```

---

### Шаг 4: Скопируйте приватный ключ в GitHub

#### 4.1. Посмотрите содержимое приватного ключа:

```bash
cat ~/.ssh/github_actions_deploy
```

Вы увидите что-то вроде:
```
-----BEGIN OPENSSH PRIVATE KEY-----
b3BlbnNzaC1rZXktdjEAAAAABG5vbmUAAAAEbm9uZQAAAAAAAAABAAABlwAAAAdzc2gtcn
NhAAAAIwAAAAdzc2gtcnNhAAABBQ...
(много строк)
...
-----END OPENSSH PRIVATE KEY-----
```

#### 4.2. Скопируйте ВСЁ содержимое

**Важно:** Скопируйте всё от `-----BEGIN` до `-----END` включительно!

#### 4.3. Добавьте в GitHub Secrets:

1. Откройте ваш репозиторий на GitHub
2. Перейдите: **Settings** → **Secrets and variables** → **Actions**
3. Нажмите **New repository secret**
4. Name: `VPS_SSH_PRIVATE_KEY`
5. Value: вставьте скопированный приватный ключ (весь текст)
6. Нажмите **Add secret**

---

## Что происходит на каждом шаге?

```
┌─────────────────┐
│ Ваш компьютер  │
│                 │
│ Приватный ключ  │──┐
│ (секретный)     │  │
│                 │  │ SSH подключение
│ Публичный ключ  │──┼─────────────────┐
│ (открытый)      │  │                 │
└─────────────────┘  │                 │
                     │                 ▼
                     │         ┌─────────────────┐
                     │         │   VPS сервер    │
                     │         │                 │
                     │         │ authorized_keys │
                     └─────────│ (список        │
                               │  разрешенных    │
                               │  ключей)        │
                               └─────────────────┘
```

1. **Приватный ключ** остается на вашем компьютере и в GitHub Secrets
2. **Публичный ключ** копируется на сервер в файл `authorized_keys`
3. Когда GitHub Actions подключается к серверу, сервер проверяет: "Есть ли этот публичный ключ в authorized_keys?"
4. Если есть - доступ разрешен ✅

## Частые проблемы

### Проблема: "Permission denied (publickey)"

**Решение:**
```bash
# На сервере проверьте права:
ssh ваш_пользователь@ваш_сервер_ip
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys
ls -la ~/.ssh/
```

### Проблема: "ssh-copy-id: command not found" (Windows)

**Решение:** Используйте Вариант Б (вручную) из Шага 2.

### Проблема: Ключ не работает после копирования

**Решение:**
1. Проверьте, что скопировали публичный ключ полностью (одну строку)
2. Проверьте права на файлы на сервере
3. Убедитесь, что используете правильного пользователя
